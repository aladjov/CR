# Acknowledgments

This project builds on outstanding open-source libraries. We are grateful to their maintainers and communities.

## Core ML & Data Science

- [scikit-learn](https://scikit-learn.org/) - Machine learning algorithms and utilities
- [XGBoost](https://xgboost.ai/) / [LightGBM](https://lightgbm.readthedocs.io/) - Gradient boosting frameworks
- [SHAP](https://shap.readthedocs.io/) - Model interpretability and explanations
- [imbalanced-learn](https://imbalanced-learn.org/) - Handling class imbalance
- [SciPy](https://scipy.org/) / [statsmodels](https://www.statsmodels.org/) - Statistical computing

## Data & Feature Infrastructure

- [Pandas](https://pandas.pydata.org/) - Data manipulation and analysis
- [PyArrow](https://arrow.apache.org/docs/python/) - Columnar data format and efficient I/O
- [Feast](https://feast.dev/) - Feature store for point-in-time correct feature serving
- [Pydantic](https://docs.pydantic.dev/) - Data validation and configuration management

## Experiment Tracking & Deployment

- [MLflow](https://mlflow.org/) - Experiment tracking, model registry, and deployment

## Visualization

- [Plotly](https://plotly.com/python/) - Interactive visualizations
- [Matplotlib](https://matplotlib.org/) / [Seaborn](https://seaborn.pydata.org/) - Statistical plotting
- [Kaleido](https://github.com/plotly/Kaleido) - Static image export for Plotly figures

## Notebook Ecosystem

- [nbconvert](https://nbconvert.readthedocs.io/) - Notebook-to-HTML tutorial export
- [Papermill](https://papermill.readthedocs.io/) - Parameterized notebook execution
- [Jupyter](https://jupyter.org/) / [IPyKernel](https://ipykernel.readthedocs.io/) - Interactive computing

## Utilities

- [Rich](https://rich.readthedocs.io/) - Terminal formatting and progress display
- [Jinja2](https://jinja.palletsprojects.com/) - Template engine for code generation
- [fsspec](https://filesystem-spec.readthedocs.io/) / [s3fs](https://s3fs.readthedocs.io/) - Cloud storage abstraction
